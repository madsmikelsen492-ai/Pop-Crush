# Pop-Crush — Bubble Blast Mania

A mobile-friendly bubble-matching arcade game packaged as a Progressive Web App (PWA). All files are in this folder's root so they can be selected together on a phone.

## Publish with GitHub Pages
1. Upload all six files in this package to the root of the `Pop-Crush` repository.
2. On GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select **main** and **/(root)**, then **Save**.
4. Wait for the Pages URL. Open it on your phone and choose **Add to Home screen** / **Install app**.

## Controls
- Tap a connected group of 2 or more matching bubbles to pop it.
- Rainbow Pop removes every bubble of the most common colour.
- Mega Pop blasts a 3×3 area.
- Clear the board for a 500-point bonus.

This is a web/PWA game package, not an Android APK. Google Play publication requires a separate Android packaging and Play Console process.
